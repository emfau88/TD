# Gezeichnete Lidvarianten

Zwei gezielte Änderungen mit dem eingebauten image_gen-Werkzeug, Referenz `../../preview/ilyra-hand-on-hip.png`: halb geschlossene und geschlossene Augen. Generierte Originale unverändert aufbewahrt. Die vollständigen Prompts stehen in `PROMPTS.txt`.

Für die Animation werden ausschließlich die registrierten Augenbereiche übernommen; außerhalb bleiben die Pixel der freigegebenen Hüftpose erhalten. Keine Mischung zweier ganzer Figuren und keine Verformung der offenen Augen als Ersatz für Lidzeichnungen.
