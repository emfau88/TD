# Prototype fonts
PixelifySans.ttf and its unchanged SIL-OFL license (OFL.txt) are retained.
SpireClearDigits.ttf is copied byte-for-byte from experiments/idle-bastion/assets/ui/fonts/.
It contains this project's independent pixel glyphs for 2, 5 and 8 only.
CSS uses it only for these code points; all remaining display glyphs use Pixelify.
Original provenance and reproduction instructions: experiments/idle-bastion/assets/ui/fonts/README.md.
